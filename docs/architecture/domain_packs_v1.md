# Domain packs V1

`_template` defines safe profile metadata. `generic_demo` proves company-neutral labels and incomplete capability discovery. `coca_cola_demo` maps the current synthetic beverage model and supplies replaceable labels/theme. Packs contain configuration, not copied analytical code or secrets. Presentation labels may vary; canonical identifiers and scientific features remain stable.

Dependency rule: core → no company pack imports; pack → canonical contract vocabulary. The Coca-Cola-oriented pack is academic, non-official, synthetic/public-donor-derived, and claims no affiliation.

# Coca-Cola-oriented demo pack

This pack contains presentation labels and mappings for the repository's synthetic beverage dataset.
It is an academic portfolio demonstration, is not official Coca-Cola HBC software, contains no
internal Coca-Cola data, and claims no affiliation or endorsement. Public donor data informed the
synthetic generator; it does not define the product master.

The generic contracts, model services, capability rules, and API do not import this pack. Select it
at the application boundary with `FSI_ACTIVE_DOMAIN_PACK=coca_cola_demo`. To onboard another company,
copy `_template`, map its exported fields to canonical contracts, validate, and enable only capabilities
whose required contracts pass.

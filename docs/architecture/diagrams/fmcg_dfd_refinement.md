## Семантика та layout

- D1 збережено: download/raw files, donor calibration та generated inputs є реальним persistent шаром. Calibration не перейменовано на довільні користувацькі налаштування.
- Kafka залишено на Level 1 трьома пунктирними потоками D2 → 1.0 → D8 → 1.0. D8 тепер означає тільки Kafka topic; ledger/idempotency/DLQ не змішано з topic і не винесено в додатковий D9. Вони описані в аудиті як деталі реалізації поза цією деталізацією.
- D3 на Data Preparation: **7 → 4**. Два входи до 2.4 об'єднано; для 2.2 та 2.3 використано вже показані символи D3. Заборонених прямих store-to-store edges немає.
- D4/D5 на ML page: **7 + 7**, як раніше. Сім незалежних scientific branches збережено.
- Прибрано довгі пояснення про «кожен рядок» і роботу 2.5; вихід 2.5 до D7 достатньо явно показує результат перевірки. Kafka footnote скорочено до «Пунктир — опціональний replay». ML footnote: «Кластери — дослідницькі; промопорівняння — не причинний ефект».
- Форми й композиція Context, Level 1 та ML page збережені; скориговано переноси, межі підписів і одну точку приєднання D3. Підписи не перетинають стрілки чи вузли.

## Фактичні обмеження запропонованих формулювань

«Параметри прогнозування» — агрегований підпис. Він не скасовує того, що поточний prediction API приймає готові feature rows. Твердження про автоматичну побудову inference features із фільтрів не додано.

MLflow importer реєструє runs усіх семи задач, але registered model versions — тільки forecasting і stockout classification. D6 охоплює version/content metadata та run identifiers; назва не означає новий універсальний registry для всіх outputs. DVC та MLflow не об'єднані в одну фізичну базу. Саме ці можливі надмірні трактування пропозицій не перенесено в модель.

## Перевірки

Context ↔ Level 1: однакові три external labels, напрями та сутності. Межі 2.0 та 3.0: той самий набір інформаційних атомів до і після refinement. Процеси мають meaningful input/output; black holes, miracles і gray holes у межах логічної моделі не виявлені. Джерельне обґрунтування збережене в [аудиті](fmcg_dfd_audit.md).

XML: 4 pages, 407 унікальних редагованих cells, 49 підписаних потоків, коректні references/geometry, без вбудованих raster images. Native mxGraph import усіх сторінок пройшов; інтерактивний GUI-тест diagrams.net не проводився.

Повторно експортовано чотири SVG та чотири PNG. **Кожен PNG реально переглянуто**: clipping, overlap, arrow directions, store repetition, optional Kafka та загальна читабельність перевірені. Базовий текст 23 px відповідає приблизно 9 pt на A4 landscape без полів.

Application code, datasets, DB, models, DVC/MLflow state, Kafka та runtime configuration не змінено. Архітектурну діаграму та IDEF0 не змінено.
